# BA1 – Property Rental Management Portal

MERN stack starter skeleton for the Property Rental Management Portal.

## Purpose

This repository intentionally contains only the basic project structure and starter files. It does **not** implement the client requirements.

Interns should use the Project Requirement Document as the source of truth and build the application from this starting point.

## Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Suggested structure

```text
BA1/
├── client/        # React frontend
├── server/        # Node.js + Express backend
├── .gitignore
└── README.md
```

## Getting started

1. Clone the repository.
2. Create the frontend and backend dependencies from their respective `package.json` files.
3. Add environment variables using the provided examples.
4. Start implementing the requirements page by page.

No business logic, database schema, API implementation, authentication implementation, or completed UI is provided intentionally.
